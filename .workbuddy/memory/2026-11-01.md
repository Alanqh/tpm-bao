# 2026-11-01 第27轮：空间计划独立 Tab + 设为默认语义

用户：「把空间计划放到新的 Tab 页。在新 Tab 页查看每个售卖空间的计划单元。第一列 function，第二列售卖空间，第三列空间计划……售卖空间和空间计划的关系就像售卖单元和售卖计划。原本的售卖空间列表支持查询某一时刻生效的售卖空间。设为生效改为设为默认——没有空间计划时 function 默认哪个售卖空间生效。」AskUserQuestion 三项均选推荐：同构平铺/Tab 名「空间计划」/默认徽标+生效态。
