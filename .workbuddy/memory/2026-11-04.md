# 第37轮（2026-11-04）：编辑锁移至基本信息下方 + 售卖单元改为空间计划叉乘自动生成 + 基本信息名称快编

## 需求
①编辑锁在基本信息卡片的**下方**（修正第36轮位置）；②**重大改动**：售卖单元在创建空间计划时确定——选 function、选维度、勾维度度量，所有度量**叉乘**生成该售卖空间下全部售卖单元；③商品详情页基本信息卡片加商品名称快捷编辑。

## 澄清口径（AskUserQuestion）
- SU Tab「创建售卖单元」按钮+弹窗**删除**，改纯只读展示；删除链路全删。
- 修改空间计划勾选变化 → **新建空间+完整叉乘**；已存在售卖单元**永不删除**（旧空间旧单元保留，售卖计划引用天然安全）。
- 勾了维度则该维度**至少勾一个度量**（拦截）；不勾维度=合法 0 维度空间（自动生成唯一单元）。

## 实现
- **编辑锁移位**：#edit-lock-bar 从基本信息卡片之前移至之后、Tab 卡片之前（justify-start 居左保留）；id 不变，renderEditLockBar 零改动。
- **空间计划弹窗三层勾选**：fn 复选（.sp-fn-check onchange=onSpFnCheck）→ 每维度小卡片（.sp-dim-check onchange=onSpDimCheck，容器 [data-dimblock]）→ 每维度度量复选（.sp-measure-check data-fn/data-dim/value，容器 [data-dimmeas]）。禁用级联：未勾 fn → 维度+度量全禁；勾 fn 未勾维度 → 度量禁；取消维度 → 度量清空+禁用。
- **confirmSpacePlan 重写**：收集 fnDims + fnMeasures（每 fn 每维度勾选度量数组）；漏度量拦截「(fn)：以下维度至少勾选一个度量：…」；空 fn 文案「至少勾选一个 function」；身份判定=`sameDims && sameMeas`（mapSort helper 对维度→度量 map 键值排序后 JSON 比较）→ 不一致则新建空间并调 genSaleUnitsForSpace 完整叉乘；row 新增 fnMeasures 字段；渲染末尾追加 renderPlan()；alert 含「已自动生成售卖单元 N 个（ids…）」。
- **genSaleUnitsForSpace(spaceKey, fn, dims, fnMeas)**：幂等（existed Set 按 saleUnitKey 去重）；0 维→唯一单元 {dim:'', measure:''}（渲染 --）；有维→按维度勾选顺序笛卡尔积，dim/measure 用 ' + ' 拼接，追加 {id:'su-'+seq, fn, spaceKey, dim, measure}；**永不删除已有单元**。
- **SU 链路删除清单**：#modal-su-confirm HTML、#su-create-btn、openSuConfirmModal/onSuFnChange/onSuSpaceChange/renderSuConfirmModalBody/renderSuZeroDimBody/confirmZeroDimUnit/renderSuDimsBody/confirmSaleUnits/removeSaleUnit 函数、suFnSel/suSpaceSel 变量；保留 saleUnitKey（genSaleUnitsForSpace 复用）。SU Tab 表头 15→14 列（删操作列）、空表 colspan 14；refreshEditControls 列表去 su-create-btn。
- **基本信息名称快编**：detail-info 模板商品名称块加 span#detail-info-name + 铅笔 openDetailNameEdit('info')；三函数支持 source（'title'默认/'info'），两处铅笔共享标题旁输入条（编辑中两铅笔均隐藏、#detail-info-name 高亮 text-violet-600）；confirm 优先更新 #detail-info-name。不依赖编辑锁。
- **copySpacePlan 第37轮化**：每 fn 新建空间后调 genSaleUnitsForSpace 叉乘；深拷贝 fnMeasures；去残留 name 字段；提示含自动生成单元数。
- **mock 自洽对齐**：defaultSpacePlans 全补 fnMeasures；defaultSaleUnits 数量与之对应（std/pre 3、pro 4、glm4 常规 4、双11 3）；glm4 su-4 修正为 sp5 单维度（dim=输入token区间，measure=0～128K，修掉旧双维不一致）。
