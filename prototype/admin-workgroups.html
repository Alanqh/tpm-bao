工作组管理

工作组按用户（subject）维度创建，用于承载用户的预留 vTPM 包与 Serverless 资源。

工作组按用户维度隔离：仅展示所选用户名下的工作组。

选择用户后展示其名下工作组列表。

工作组列表

实体 ID code 超量路由 vTPM 包 Serverless 模型列表 备注 创建时间 操作

使用场景（资源匹配优先级）

场景 ① 请求未指定工作组

到 default 默认工作组中，按 playground_name 查找对应资源（对应现状）。

场景 ② 指定工作组 + playground_name

到指定工作组内查找对应模型的资源，可命中多个 vTPM 包与 Serverless；同一模型 vTPM 包优先于 Serverless 使用。

场景 ③ 仅指定工作组

在该工作组内使用用户配置的资源：即下方「生效模型列表」＝vTPM 覆盖模型 ∪ Serverless 模型列表。

该用户暂无工作组

未创建工作组时，该用户的资源默认落到 default 工作组。
