预留 vTPM 购买须知

请您在购买前仔细阅读以下规则。提交购买意向即视为您已理解并同意相关内容。

适用范围：本须知适用于通过官网直销渠道购买的预留 vTPM 资源包，包括售卖规则、SLA 承诺、模型更换及退款等事项。

购买规则

1. 售卖规格

  • 售卖时长：可选 30 天、60 天、90 天、120 天、150 天、180 天，暂不提供小时/天档或超过 180 天的长周期售卖。
  • 起购数量：1 vTPM；单用户单次最多可购买 10 份（每份 100 vTPM）。
  • 模型绑定：购买时必须选择具体 model name，资源按模型强隔离。

2. 订单与库存

  • 当前一期走官网飞书表单申请 + 销售跟进 + 线下合同流程，后台通过飞书表格配置购买记录。
  • 订单成立前需完成资源锁定校验，库存不足时订单不成立，可选择候补或替代模型。
  • 资源按先到先得原则分配；销售可为企业客户锁库存，锁库存额度由后台配置。

3. 续约规则

  • 在有效预留 vTPM 存续期且 SKU 售卖窗口期内，用户可任意续约。
  • 下单时可勾选自动续约；续约通知节奏为到期前 T-7、T-3、T-1。
  • 到期日超过停售日期的续约不被接受。

4. 试用与退订

  • vTPM 库存稀缺，暂不开放普遍免费试用。
  • 销售可针对企业客户申请必要代金券抵扣，但不设计普遍机制。

SLA 保障与赔付规则

1. SLO 承诺

  • TPM：每分钟可消耗 N vTPM（N = 购买量），时间粒度为分钟级，不承诺瞬时峰值。
  • 延迟：P95 TTFT、P95 TPOT 分钟级承诺，具体阈值待性能测试矩阵确定后公示。
  • 系数公开透明、可实时试算；已售 vTPM 的系数冻结，调整仅对后续生效。

2. 违约事件分类

类别事件判定
A 类vTPM 速率违约固定分钟窗口内，实际需求 ≤ 购买量但被限流/拒新
B 类延迟违约固定分钟窗口内 P95 TTFT 或 TPOT 超阈值
C 类可用性违约固定分钟窗口内请求全部失败（5xx/超时）

3. 赔付阶梯

  • 赔付基数：当月已付预留费（不含按量消费）。
  • 累计违约 ≤ 3 分钟/月：容忍窗口，赔付 0%。
  • 累计违约 4–30 分钟/月：赔付 10%。
  • 累计违约 31–120 分钟/月：赔付 30%。
  • 累计违约 > 120 分钟/月：赔付 100%，并触发退出协商权。

4. 维护与申诉

  • 维护窗口提前 7 天通告，窗口内不计违约。
  • 上游故障（GPU 宕机等）仍算违约，可用不可抗力条款封顶赔付。
  • 用户可在违约事件推送后 30 天内申诉；平台日志缺失时默认采信用户申诉。

模型更换规则

1. 合约期内原则禁止更换 model name

  • 预留 vTPM 购买时已绑定具体 model name，合约期内不支持直接切换模型。
  • 平滑升级的模型若复用已有 model name，对用户无感知，不视为更换。

2. 确需更换的处理方式

  • 用户需走客服工单申请“残值退回 + 自行换购”流程，系统不提供功能性换购入口。
  • 残值 = 购买金额 − max(已过时长折算值, 实际使用 tokens 按 Serverless 计价的价值)。
  • 暂不收取手续费；退款通过线下渠道处理。

3. 模型停售与停服

  • 停售：不再售卖新订单，已存续合约不中断；不再接受到期日在停售日期之后的续约。
  • 停服：确需提前停止服务时，平台承担迁移成本并按“平台缺失需强行转换”规则补偿（vTPM 量或时长）。

退款规则

1. 退款触发条件

  • 用户主动退订或换购另一个模型的 vTPM。
  • 发生 SLA 严重违约（> 120 分钟/月）触发退出协商后，确需退费。

2. 残值计算

残值 = 购买金额 − max(已过时长折算值, 实际使用 tokens 按 Serverless 计价的价值)
  • 取 max 是为了避免“用得多反而退得少”的悖论。
  • 赔付场景下按损失填平原则，最大不超过订单金额。

3. 退款路径

  • 一期通过客服工单线下处理，退款以抵扣券或服务费返还形式发放。
  • 退款到账时间以财务流程为准，通常为 7–15 个工作日。

端点绑定说明

购买时需选择 model_name 的绑定方式，不同模式决定了超量请求的处理逻辑。

模式行为超量请求处理
公共 model name
默认		 超限请求自动降级到该模型的 Serverless 流量 按 Serverless tokens 计量计费
专属 model name 用户自行控制是否启用 vTPM，资源独占性更强 超量请求拒绝（429），用户自行处理降级
