交付详情 · 使用指南

您的专属 API 请求 model_name（请以该名称发起请求）

格式：/Pool 对象名/model —— 由您账号（subject_id）下 Pool 对象与模型名称组合生成，路由至您预留的专属算力资源。

如何使用

1

使用本资源包所属账号（subject_id）对应的 API Key 发起请求，Base URL 与平台公开接口保持一致。

2

请求 body 中的 model 字段请填写上方最终 model_name（请勿直接填写购买时提交的原始模型名称，那样不会路由到您的预留算力）。

3

请求将按该资源包绑定的折算系数计量 vTPM 用量；请结合监控页合理评估业务负载。
