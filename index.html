什么是预留 vTPM

面向大模型推理场景的算力资源切片服务

资源切片预留

以 vTPM 为单位购买模型算力，无需独占完整实例，也能获得明确的资源保障。

分钟级 SLO 保障

在购买容量范围内，提供分钟级 vTPM 吞吐及 P95 延迟保障。具体指标以对应模型的服务等级协议为准。

多维用量折算

根据输入长度、输出长度、缓存命中情况等因素，将实际 tokens 统一折算为 vTPM 用量，准确反映不同请求的资源消耗。

透明、可试算

购买前可查看对应模型的折算系数，并试算不同业务场景下的预计容量与成本。订单生效后，适用于该订单的折算系数保持稳定。

为什么选择预留 vTPM

更灵活、更稳定、更可预期的模型服务方式

服务能力更可预期

已购买的 vTPM 对应明确的预留资源。在容量范围内，可获得比 Serverless API 更稳定的吞吐与延迟表现。

购买粒度更灵活

无需承担完整预留实例的资源成本，可从 1 vTPM 起购，并根据业务规模组合购买。

容量与成本更易规划

采用固定周期、预付费的资源租约模式，帮助企业提前规划推理容量与预算。

适合生产业务的自然波动

相比 Serverless API，预留 vTPM 支持更快的请求爬坡，适合负载有自然波动的生产业务。
